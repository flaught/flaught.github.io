Flaught

Your PR's designated skeptic.

The reviewer should not be the author. A model reviewing code it wrote itself tends to agree with its own choices — same blind spots, same rationalizations. Flaught decouples the two: point it at any LLM, independent of whatever wrote the code, and get a genuinely adversarial second opinion instead of an echo.

bash
# install
npm install -g @flaught/core
# scaffold config + prompts, then review vs main
flaught init
flaught review --base main

Runs in GitHub Actions, GitLab CI, or any shell. No API key needed for the deterministic pass (flaught review --no-llm); set GROQ_API_KEY for the full LLM pass. Provider config →

01Five stages, one skeptical pass

Config→ Context assembly→ Deterministic tools→ LLM adversarial pass→ Test inversion→ Scope-creep detection
Noise budget→ Severity gate→ Exit code (0 / 1 / 2)
  • Context assembly
    Diff, changed files, and a one-hop dependency neighborhood so findings carry blast radius, not just a line number.
  • Deterministic tools deterministic
    Semgrep, a linter, and a vuln scanner. Every finding is tagged source_type: "deterministic" so you know what came from a tool.
  • LLM adversarial pass llm
    Structured skeptical review of security, architecture, scope-creep, and test quality — tagged source_type: "llm", distinct from the tool findings.
  • Test inversion
    Runs the test suite on pre-change code and flags tests that pass on both sides — cheap mutation testing that catches vacuous tests.
  • Scope-creep detection
    Heuristic plus LLM; flags hunks unrelated to the PR's stated intent.

Output: a Markdown PR comment plus a versioned JSON artifact you can keep — one snapshot per run, for trend tracking.

03Review with a different model than the one that wrote the code

Self-review is the weak spot in AI-assisted development. The model that wrote your PR is primed to defend it. Flaught breaks that correlation — swap reviewers with zero code change, just update .advreview.yml.

A sane pairing: code with Claude, review with GPT-4o or Groq. Code with Copilot or GPT, review with Claude. Code with anything, review with a different anything. Any OpenAI-compatible endpoint works via base_url; Anthropic has its own native adapter since its Messages API isn't OpenAI-shaped.

05The honest caveat

⚠ The JSON artifact is evidence that scrutiny occurred, not evidence that findings are correct. LLM-asserted findings may include hallucinations. Deterministic-tool findings have their own false-positive rates. Treat this as a prompt for human review, not audit-truth.
